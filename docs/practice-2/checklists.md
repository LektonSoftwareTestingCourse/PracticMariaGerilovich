## 1. Дымовое тестирование

Быстрая оценка работоспособности системы после сборки.

### Gateway
- [ ] Проверить, что Gateway доступен и отвечает на health-check.
- [ ] Проверить, что health-check Gateway показывает все downstream-сервисы (Switch, Authorization, Card Management, Logger) как доступные.
- [ ] Проверить, что на запрос к Gateway приходит корректный ответ.

### Switch
- [ ] Проверить, что Switch доступен и отвечает на health-check.
- [ ] Проверить, что health-check Switch подтверждает доступность Authorization.
- [ ] Если Switch недоступен, проверить, что система возвращает понятную ошибку.

### Terminal Simulator
- [ ] Проверить, что Terminal Simulator запущен и доступен.
- [ ] Проверить, что Terminal Simulator может отправить хотя бы одну тестовую транзакцию.

### Merchant Simulator
- [ ] Проверить, что Merchant Simulator запущен и доступен.
- [ ] Проверить, что Merchant Simulator может отправить хотя бы одну тестовую транзакцию.

### Transaction Logger
- [ ] Проверить, что Transaction Logger доступен и отвечает на health-check.
- [ ] Проверить, что сервис сообщает число сохранённых транзакций.

### Web Dashboard
- [ ] Проверить, что Web Dashboard открывается.

### Сквозная проверка
- [ ] Проверить, что одна тестовая транзакция проходит по всей цепочке до Transaction Logger.

## 2. Критический путь

Проверка ключевых сценариев процессинговой цепочки.

### Gateway
- [ ] Проверить, что корректный запрос транзакции принимается и передаётся дальше в Switch.
- [ ] Проверить, что некорректный запрос отклоняется с понятной ошибкой валидации.
- [ ] Проверить, что запросы к картам, симуляторам и дашборду проксируются в нужный сервис.
- [ ] Проверить, что при превышении лимита запросов Gateway ограничивает нагрузку.
- [ ] Проверить, что при недоступности downstream-сервиса возвращается ошибка о недоступности.

### Switch
- [ ] Проверить, что по номеру карты определяется эмитент и запрос направляется в Authorization.
- [ ] Проверить, что после ответа Authorization транзакция отправляется в Transaction Logger.
- [ ] Проверить, что ответ возвращается в Gateway.
- [ ] Если BIN карты неизвестен, проверить, что транзакция отклоняется.
- [ ] Если Authorization недоступен, проверить, что Switch повторяет запрос и в итоге отклоняет транзакцию.
- [ ] Если брокер сообщений недоступен, проверить, что одобренная транзакция не теряется (резервирование откатывается).

### Terminal Simulator
- [ ] Проверить, что Terminal Simulator формирует и отправляет корректную транзакцию по имеющимся картам.
- [ ] Проверить, что Terminal Simulator корректно обрабатывает ответ на отправленную транзакцию.

### Merchant Simulator
- [ ] Проверить, что Merchant Simulator формирует и отправляет корректную транзакцию по имеющимся картам.
- [ ] Проверить, что Merchant Simulator корректно обрабатывает ответ на отправленную транзакцию.

### Transaction Logger
- [ ] Проверить, что принятая транзакция сохраняется в базе.
- [ ] Проверить, что повторная отправка той же транзакции не создаёт дубликата.
- [ ] Проверить, что транзакцию можно найти по номеру карты, статусу, дате и другим фильтрам.

### Web Dashboard
- [ ] Проверить, что на дашборде отображаются статистика и поток транзакций в реальном времени.
- [ ] Проверить, что данные на дашборде соответствуют данным из Transaction Logger.
